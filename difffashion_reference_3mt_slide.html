DiffFashion · Reference-Based Fashion Design

Give a garment a new look, without losing its shape

Designers may like the structure of one clothing image, but want the color, texture, or visual feeling of another reference image. DiffFashion studies how AI can combine them.

The challenge
Style transfer often changes too much: the pattern moves, the garment shape collapses, or the result no longer looks like real clothing.

Simple metaphor: keep the “cut” of the clothing, borrow the “fabric impression” from a reference image, and let diffusion gradually redraw a realistic new design.

Input A

Clothing structure

The source garment provides the outline, category, and shape that should be preserved.

Input B

Reference appearance

The reference image provides visual inspiration: color, texture, pattern, or style.

Output

New fashion design

DiffFashion transfers appearance while using structure-aware guidance to keep the garment realistic.

Unsupervised No need for perfectly paired “before and after” fashion images.
Mask guidance Focuses transfer on the clothing foreground and protects garment structure.
ViT guidance Uses visual features to balance appearance transfer and structure preservation.
